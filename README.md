# purrfeed-data
Content catalog for the Purrfeed iOS app.
- `catalog.json` — vertical kitten videos from the official Pexels API (rebuilt daily by `build_catalog.py`). Every item carries creator credit + Pexels page link; the app shows "Video by <creator> on Pexels".
- `products.json` — curated cat products (Amazon Associates search links). As an Amazon Associate we earn from qualifying purchases.
